# ওয়েব (Next.js + React + TypeScript)
এখনও তৈরি হয়নি। রিপোজিটরির রুট থেকে চালান: `npx create-next-app@latest apps/web --typescript`।
components/, layouts/, services/, state/, hooks/, utils/ ব্যবহার করুন। শুধু `/api/v1`-এর সাথে যোগাযোগ করুন। রেসপনসিভ ডিজাইন, নির্দিষ্ট প্রস্থ নয়। লেখার জন্য i18n সিস্টেম ব্যবহার করুন।
